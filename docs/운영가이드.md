# BrainCo Revo2 Basic 로봇 손 — 운영·실행 가이드

> 최초 작성 2026-07-09 · 실제 하드웨어(Revo2 Basic 오른손)로 개폐 동작 및 ROS 2 파이프라인까지 검증 완료된 절차입니다.
> **각 코드블록은 통째로 복사해 터미널에 붙여넣으면 됩니다.**

> **경로 표기 안내**
> 이 문서의 `~/1/brainco` 는 **참조 설치 위치**입니다. 다른 위치에 두었다면 그 경로로 바꾸어 읽으십시오.
> 본 저장소의 파이썬 스크립트는 환경변수 `STARK_SDK_DIR` 로 공식 SDK 예제 폴더를 지정할 수 있습니다.
>
> ```bash
> export STARK_SDK_DIR=$STARK_SDK_DIR
> ```
>
> 문서에 적힌 시리얼 번호는 개별 기기 식별자이므로 `BCXRR2147J25XXXXX` 로 가렸습니다.
> 실제 로그에는 보유 기기의 고유 번호가 출력됩니다.

## 1. 최초 1회만 하면 되는 준비 (이미 완료됨 ✅)

아래는 똘똘이가 이미 처리해 둔 항목입니다. **재설치/재실행 불필요**. 참고용으로만 기록합니다.

```bash
# (참고) SDK·의존성 설치 — 이미 설치됨
pip3 install bc-stark-sdk==0.9.5 colorlog

# (참고) 시리얼 포트 권한 그룹 등록 — 이미 등록됨 (재로그인 시 영구 적용)
sudo usermod -aG dialout $USER
```

### 1-1. 포트 권한 점검 (문제 생길 때만)

USB를 뽑았다 꽂았거나 재부팅 후 `Permission denied`가 뜨면, 아래 한 줄로 즉시 해결됩니다. (비밀번호 입력 필요)

```bash
sudo chmod a+rw /dev/ttyUSB0
```

> 재로그인(로그아웃 후 재접속) 또는 재부팅을 한 번 거치면 dialout 그룹이 영구 적용되어, 이후로는 이 명령조차 필요 없습니다.

## 2. 실행법 A — 직접 Python SDK (가장 간단, 첫 확인용 권장)

ROS2 없이 파이썬 한 줄로 손을 움직입니다. **동작 확인은 이 방법이 가장 빠릅니다.**

### 2-1. 손가락 모두 펴기 (가장 안전한 첫 테스트)

```bash
cd $STARK_SDK_DIR/python/revo2 && python3 open_hand.py
```

### 2-2. 종합 제어 예제 (위치/속도/전류/상태읽기)

```bash
cd $STARK_SDK_DIR/python/revo2 && python3 revo2_ctrl.py
```

### 2-3. 동작 시퀀스 데모

```bash
cd $STARK_SDK_DIR/python/revo2 && python3 revo2_action_seq.py
```

> **정상 동작 신호**: 로그에 `Found device ... slave_id: 0x7F`, `Device SN: BCXRR2147J25XXXXX` 가 뜨고 손가락이 움직이면 성공입니다.

---

## 3. 실행법 B — ROS2 (keyboard_control.py 키보드 제어)

키보드로 실시간 제스처 제어를 하는 방식입니다. **터미널 2개**가 필요합니다.

> ⚠️ 실행법 A와 B를 **동시에 돌리지 마십시오**. 둘 다 `/dev/ttyUSB0`를 열어 충돌합니다.

### 3-1. [터미널 ①] 컨트롤러 노드 실행 (시리얼 ↔ ROS2 다리)

이 창은 **켜 둔 채로** 두십시오. 종료하면 손 제어가 끊깁니다.

```bash
cd $STARK_SDK_DIR/ros2_stark_ws && ./stark_serial_manager.sh launch
```

> **정상 동작 신호**: `Slave[127] SKU Type: 1, Serial Number: BCXRR2147J25XXXXX ...` 로그가 뜨면 하드웨어 연결 성공입니다.

### 3-2. [터미널 ②] 키보드 제어 프로그램 실행

**새 터미널 창**을 열고 아래를 붙여넣으십시오.

```bash
source /opt/ros/humble/setup.bash
source $STARK_SDK_DIR/ros2_stark_ws/install/setup.bash
python3 src/keyboard_control.py      # 이 저장소를 내려받은 폴더에서 실행
```

### 3-3. 키 조작표

프로그램 창이 뜬 상태에서 아래 키를 누르면 손이 움직입니다.

| 키 | 동작 | 키 | 동작 |
|----|------|----|------|
| `p` | ✋ 보 (손 펴기) | `o` | 👌 OK |
| `r` | ✊ 바위 (주먹) | `t` | 👍 엄지 척 |
| `s` | ✌️ 가위 | `v` | ✌️ 브이 |
| `0`~`9` | 쥐는 정도 (0=펴기 ~ 9=쥐기) | `h` | 💗 하트 |
| `Space` | 모든 손가락 펴기 | `l` | 🤟 러브 |
| `?` | 도움말 다시 보기 | `g` | 🔫 총 모양 |
| `q` | 종료 | | |

**개별 손가락 테스트** (Shift + 숫자):
`!`=엄지(각도1), `@`=엄지(각도2), `#`=검지, `$`=중지, `%`=약지, `^`=소지

## 4. ROS2 상태 점검·수동 제어 (선택)

### 4-1. 노드/토픽이 잘 떠 있는지 확인

```bash
source /opt/ros/humble/setup.bash
source $STARK_SDK_DIR/ros2_stark_ws/install/setup.bash
ros2 node list          # /stark_node 가 보여야 정상
ros2 topic list | grep motor
```

### 4-2. 손 현재 상태(위치) 실시간 모니터링

```bash
source /opt/ros/humble/setup.bash
source $STARK_SDK_DIR/ros2_stark_ws/install/setup.bash
ros2 topic echo /motor_status
```

### 4-3. keyboard_control 없이 토픽으로 직접 제스처 명령 (예: 브이)

```bash
source /opt/ros/humble/setup.bash
source $STARK_SDK_DIR/ros2_stark_ws/install/setup.bash
ros2 topic pub --once /set_motor_multi_127 ros2_stark_msgs/msg/SetMotorMulti \
"{slave_id: 127, mode: 5, positions: [1000,1000,0,0,1000,1000], speeds: [0,0,0,0,0,0], currents: [0,0,0,0,0,0], pwms: [0,0,0,0,0,0], durations: [500,500,500,500,500,500]}"
```

손 펴기(보):

```bash
source /opt/ros/humble/setup.bash
source $STARK_SDK_DIR/ros2_stark_ws/install/setup.bash
ros2 topic pub --once /set_motor_multi_127 ros2_stark_msgs/msg/SetMotorMulti \
"{slave_id: 127, mode: 5, positions: [0,0,0,0,0,0], speeds: [0,0,0,0,0,0], currents: [0,0,0,0,0,0], pwms: [0,0,0,0,0,0], durations: [500,500,500,500,500,500]}"
```

> `SetMotorMulti` 필드: `slave_id`(127), `mode`(5=위치+시간), `positions`(0~1000×6), `durations`(ms×6).
> positions 순서 = `[엄지, 검지, 중지, 약지, 소지, 손목]`.

## 5. 종료 방법

- **키보드 제어 종료**: 터미널 ②에서 `q` 입력.
- **컨트롤러 노드 종료**: 터미널 ①에서 `Ctrl + C`.
- **강제 정리(포트 안 놓일 때)**:

```bash
pkill -f stark_node
```

## 6. 문제 해결 (Troubleshooting)

| 증상 | 원인 | 해결 |
|------|------|------|
| `Permission denied: '/dev/ttyUSB0'` | 포트 권한 | `sudo chmod a+rw /dev/ttyUSB0` (또는 재로그인) |
| `No available port found` | USB 미연결/포트 다름 | 케이블 재연결, `ls /dev/ttyUSB*` 확인 |
| `No module named 'bc_stark_sdk'` | SDK 미설치 | `pip3 install bc-stark-sdk==0.9.5 colorlog` |
| `ros2_stark_msgs` 임포트 오류 | ROS2 미소스 | 터미널 ②의 `source ...install/setup.bash` 두 줄 실행 |
| 손이 안 움직임 (ROS2) | 컨트롤러 노드 안 뜸 | 터미널 ①의 `stark_serial_manager.sh launch` 먼저 실행 |
| A/B 동시 실행 후 멈춤 | 포트 충돌 | 한쪽만 실행. `pkill -f stark_node` 후 재시도 |

## 7. 안전 수칙

1. 첫 실행은 항상 **펴기(open_hand.py 또는 `p`키)** 로 시작 — 급작스러운 주먹은 끼임 위험.
2. 손이 물체에 걸려 모터가 멈추면 과전류 보호가 걸립니다. 오래 물리지 마십시오.
3. **한 번에 한 가지 방식(A 또는 B)만** 실행.
4. 카메라 손추적(`hand_tracking_control.py`)은 `mediapipe`/`opencv` 추가 설치가 필요합니다(미설치, 별도 요청 시 안내).
