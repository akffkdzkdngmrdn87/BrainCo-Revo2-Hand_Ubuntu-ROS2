## 경로 표기에 관하여

문서에 등장하는 `~/1/brainco` 는 **참조 설치 위치**입니다. 다른 위치에 설치했다면 해당 경로로
바꾸어 읽으십시오. 본 저장소의 파이썬 스크립트는 환경변수 `STARK_SDK_DIR` 로 제조사 예제
폴더 위치를 지정할 수 있습니다.

## 개별 기기 식별자

문서 내 장치 시리얼 번호는 `BCXRR2147J25XXXXX` 형태로 가렸습니다. 실제 실행 로그에는
보유 기기의 고유 번호가 출력되므로, 문서의 값과 다른 것이 정상입니다.
