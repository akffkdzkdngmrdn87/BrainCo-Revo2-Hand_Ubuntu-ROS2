## 영상 내용

`src/hand_keyboard.py` 로 로봇 손을 실시간 제어하는 장면입니다. 프리셋 제스처(보·주먹·브이·
러브·총·숫자)와 손가락 단계 순환이 순차적으로 나타납니다. 촬영 대상은 로봇 손 본체이며
인물의 얼굴은 포함되지 않았습니다.

## 인코딩 규격의 근거

원본은 스마트폰 촬영본으로 **HEVC(H.265) · 73 MB** 였습니다. 다음 두 가지 이유로 재인코딩하였습니다.

1. **브라우저 호환성** — HEVC는 다수 브라우저의 `<video>` 요소에서 재생되지 않습니다.
   웹에서 확실히 재생되는 **H.264 High / yuv420p** 로 변환하였습니다.
2. **첨부 용량 제한** — GitHub 무료 플랜의 영상 첨부 한도는 10 MB 입니다.
   원본 73 MB 는 README 플레이어로 삽입할 수 없습니다.

`-movflags +faststart` 를 적용하여 moov 원자를 파일 앞에 배치했으므로, 전체를 내려받기 전에
재생이 시작됩니다. 원본 HEVC 파일은 저장소에 포함하지 않았습니다.
